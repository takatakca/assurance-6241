Méthode et utilisation

Travailler avec le dossier maître

1. Ouvrir

Commencer par OUVRIR-LES-DOSSIERS.html dans OneDrive, ou par la page d’accueil du site.

2. Trouver

Rechercher un nom, une facture ou une expression. Tous les mots sont recherchés; les guillemets conservent une expression. Les accents et la casse sont ignorés.

3. Vérifier

Lire l’extrait, ouvrir la pièce et vérifier la page. Les copies exactes sont regroupées; une facture révisée demeure à rapprocher de ses autres versions.

4. Compléter

Enregistrer les nouveaux originaux dans leur dossier thématique. L’index et le site doivent ensuite être régénérés; leur date reste affichée.

Lecture hors connexion et travail à distance

Dans OneDrive, choisir « Toujours conserver sur cet appareil » pour ce dossier si vous devez travailler sans connexion. La page locale lit les fichiers voisins. Le site publie une copie datée; il n’est pas un éditeur partagé et ne synchronise pas automatiquement les modifications.

Les sous-dossiers existants contiennent les originaux. Les sections du maître sont des vues organisées pour éviter de multiplier les copies. Les courriels, déclarations, analyses et extractions restent identifiés. Les anciens index sont accessibles comme archives, mais leurs anciens champs interactifs ne servent pas à la recherche actuelle.

Provenance et contrôle des pièces

Les originaux, les déclarations et les analyses sont identifiés par leur provenance. Les doublons et les versions d’une facture ne s’additionnent pas. Une extraction OCR reste à contrôler sur la pièce originale. Les documents à obtenir et les vérifications ouvertes figurent dans les synthèses de chaque dossier.

Les pièces d’origine restent dans leurs dossiers. L’index est une copie de travail datée; une recherche sans résultat ne démontre pas l’absence d’une pièce. Les synchronisations OneDrive et GitHub sont distinctes.
