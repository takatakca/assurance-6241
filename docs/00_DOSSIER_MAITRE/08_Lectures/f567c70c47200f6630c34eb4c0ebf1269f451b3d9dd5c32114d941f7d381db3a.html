Les originaux, les déclarations et les analyses sont identifiés par leur provenance. Les doublons et les versions d’une facture ne s’additionnent pas. Les pièces d’origine restent dans leurs dossiers. L’index est une copie de travail datée; une recherche sans résultat ne démontre pas l’absence d’une pièce. Les synchronisations OneDrive et GitHub sont distinctes.
