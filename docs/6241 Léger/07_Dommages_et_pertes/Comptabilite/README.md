# Master comptable — 6241 boulevard Léger

Le classeur sépare les pertes nouvelles à établir, les ventes, les écritures historiques, les factures/devis et les indemnités mentionnées. Les cellules jaunes sont à compléter sur une copie de travail. Les montants absents restent « n.d. »; ils ne sont pas ramenés à zéro.

Les pièces vérifiées sont référencées par numéro, cellule, ligne ou page. Le JSON fournit leurs chemins et empreintes SHA-256. Aucun total final de pertes ni total bancaire encaissé n’est établi. Les cinq versions Harmony ne sont pas cinq factures cumulables.

Consulter l’onglet Méthode avant mise à jour. Formules et plages de synthèse doivent être prolongées lors de tout ajout de ligne.
