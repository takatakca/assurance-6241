Lien avec la réunion d'assurance
Le désaccord sur la facture de déménagement ne chiffre pas les dommages aux appareils. Faire préciser si l'assureur
conteste la responsabilité, la causalité, la valeur ou seulement les pièces justificatives. Pour chaque objection, consigner
le code du bien, la pièce, l'explication et le document permettant de décider. Les observations techniques doivent être
examinées même si le litige de paiement subsiste.
