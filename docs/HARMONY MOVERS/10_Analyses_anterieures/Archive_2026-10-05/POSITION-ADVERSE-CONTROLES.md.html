Lien avec la réunion d'assurance

Le désaccord sur la facture de déménagement ne chiffre pas les dommages aux appareils. Faire préciser si l'assureur conteste la responsabilité, la causalité, la valeur ou seulement les pièces justificatives. Pour chaque objection, consigner le code du bien, la pièce, l'explication et le document permettant de décider. Les observations techniques doivent être examinées même si le litige de paiement subsiste.

Règle commune aux trois dossiers

Les originaux, les déclarations et les analyses sont identifiés par leur provenance. Les doublons et les versions d’une facture ne s’additionnent pas. Une extraction OCR reste à contrôler sur la pièce originale. Les documents à obtenir et les vérifications ouvertes figurent dans les synthèses de chaque dossier.
